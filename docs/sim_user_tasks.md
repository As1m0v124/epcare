# 模拟用户测试场景（3 角色 × 5 个任务）

> 依据毕设规划第 3 节：三种角色各设计一组任务场景，用脚本或智能体扮演用户在网页上完成，
> 记录完成率、步骤数、耗时、出错点和机器人实际执行成功率。
> **状态**：场景已定义；执行需要真机（或 replay 模式跑流程），结果表待填。

## 角色 A · 家属（family1 / family123）

| # | 任务 | 步骤预期 | 判定标准 | 完成率/耗时/出错点 |
|---|---|---|---|---|
| A1 | 让机器人找「奶奶的老花镜」 | 登录 → 找东西页 → 输入 → 读取结果（截图+位置+置信度） | 返回至少 1 个候选并显示截图 | 待填 |
| A2 | 查看今天的巡检报告 | 登录 → 巡检任务/看板 → 读取发现/捡起/告警统计 | 数字与后端一致 | 待填 |
| A3 | 录入 4 条收纳示例并确认归纳结果 | 收纳习惯页 → 输入示例 → 归纳 → 查看规则 | 规则文本非空、包含至少 1 个位置 | 待填 |
| A4 | 修改归纳出的规则（家属纠正） | 编辑示例 → 重新归纳 | 新规则反映纠正 | 待填 |
| A5 | 让机器人「去卧室找遥控器，先别捡，拍张照」 | 助手输入 → 去执行 → 结果含截图 | 截图存在且不触发抓取 | 待填 |

## 角色 C · 设备管理员（admin / admin123）

| # | 任务 | 步骤预期 | 判定标准 | 完成率/耗时/出错点 |
|---|---|---|---|---|

## 执行方式

1. 真机模式：`bash start.sh real`，按表逐条操作并记录（秒表 + 截图）；
2. 无真机时先用 replay 跑流程（A3/A4/B1/B2/B4/C1/C2/C4/C5 均可完整验证）；
3. 每轮结束填「完成率 / 步骤数 / 耗时 / 出错点」，汇总进阶段 3 的系统测试章节。
