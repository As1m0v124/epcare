# 问题台账（Known Issues）

> 记录项目以来遇到的所有问题、根因与处理，持续更新。按出现顺序编号。

## 环境 / SDK

| # | 问题 | 根因 | 处理 | 状态 |
|---|---|---|---|---|
| 1 | `uv pip install robomaster` 无 macOS wheel | 官方只发 manylinux/win wheel | 拆 manylinux wheel 装纯 Python 部分 + 3 补丁（`scripts/install_robomaster_mac.sh`） | ✅ 已解 |
| 2 | SDK `initialize()` 崩溃 | 相机模块初始化急切创建视频解码器（macOS 无 libmedia_codec） | 解码器按需创建 + 流启动保护 | ✅ 已解 |
| 3 | 命令行传参连不上（`conn_type='sta'`） | SDK 用 `is` 比较连接类型，非驻留字符串身份不等 | `conn.py` 三处 `is` → `==` | ✅ 已解 |
| 4 | macOS 无视频流 | 解码器仅 Linux/Windows 二进制 | **TCP 40921 直连裸 H.264 + PyAV 解码**（含逐块解码、看门狗、重连） | ✅ 已解 |
| 5 | 机械臂位置出现 42 亿异常值 | SDK 用无符号 `<II` 解码位置，y 负值溢出 | 改为有符号 `<ii`（补丁入安装脚本） | ✅ 已解 |
| 6 | `servo.drive_speed` 锁死机械臂 | 舵机速度模式与机械臂高层控制互斥 | 禁用；线性动作改用闭环步进 | ✅ 规避 |
| 7 | 机械臂下降/小步不动 | 单步 <8–10mm 被静默忽略（动作仍返回成功） | 步长统一 ≥10mm | ✅ 已解 |
| 8 | 机械臂「到限位」误报 | 1 秒无位移判定过急；限位随姿态耦合 | 3 秒窗口 + 连续两次失败才提示 | ✅ 已解 |
| 9 | 低电量时机械臂指令成功但不动 | ≤40% 电量功率保护 | 记录规律；充至 >80% 恢复；服务设 25% 拒动 | ✅ 已知 |
| 10 | 跨网段找不到机器人 | Mac 与机器人不同网段，SDK 扫描选错网卡 | `EP_IP` 固定 IP 直连（`config.ROBOT_IP_STR`） | ✅ 已解 |
| 11 | 整机掉线（ping/广播皆失败） | 机器人 Wi-Fi/系统挂起 | 关机重启；服务加自动重连（12 次×5s） | ✅ 已解 |
