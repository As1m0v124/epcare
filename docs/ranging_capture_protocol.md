# EP 居家测距集采集协议（200 张 · F1 标定）

> 用途：标定「框底边/地面接触点 → 真实距离」，并对比三种测距做法（A 固定针孔 / B 地平面标定 / C 深度标定）。
> 不属于 11/10 检查点（检查点的 F1 用 NYU-D + DA-2K 已交）；这是阶段 2 的真实场景标定。
> 现状：`data/ep_ranging` 只有 2026-10-31 的 **1 张**（3 个物体都在估计的 0.5m），且当时没点地面接触点，**评测不可用**；实际从 0/200 开始。

## 一、采集前准备（一次，约 10 分钟）

1. 机器人放平，相机高度/俯仰固定，用卷尺量：
   - 相机镜头离地高度（默认 0.25m）；
   - 镜头下俯角（目测/量角器，默认 0，写进 `--camera-pitch`）；
2. 量一块地砖的边长（实验室常见 600mm；不是 600mm 就传 `--tile-m`）；
3. 选 3 种地面：瓷砖、木地板、地毯；2 种光照：白天、夜间开灯；
4. 准备 3–5 个日常物体（水瓶、盒子、拖鞋、收纳包、纸杯等），高度 5–30cm。

## 二、每张图的流程（约 1 分钟）

```bash
cd ~/ep-project
bash start.sh real          # 会自动停掉旧服务，连真机
ai312/bin/python scripts/collect_ranging_data.py --out data/ep_ranging --n 200 \
  --tile-m 0.6 --camera-height 0.25 --camera-pitch 0
```

1. 把物体沿地砖边线摆好（不要叠放、不要互相遮挡）；
2. 回车拍照；
3. 输入物体与距离：`水瓶:1.2 盒子:2t 收纳包:0.5`
   - 纯数字 = 米；`t` = 地砖数（`2t` = 2 块砖）；
4. 弹出图像窗口，**依次点击每个物体与地面的接触点**（不是物体中心，是底部贴地那一点）；
   - 点错可按 ESC 整张跳过；跳过会标 `no_point`，评测时忽略；
5. 换下一个位置，重复。

**距离取值建议**：0.5 / 0.8 / 1.2 / 1.6 / 2.0 / 2.4m（用砖数就是 1t/1.5t/2t/3t/3.5t/4t），
每个距离至少 2 张不同角度；同一张图内物体不要都在同一深度，至少 1 近 1 远。

## 三、先采 20 张 pilot，再扩到 200

先采 **20 张**（瓷砖/木地板各 10，白天），跑一次 `eval_ep_ranging.py`：
- 若 B（地平面标定）AbsRel 明显低于 A、且参数稳定，再按下面配额扩采；
- 若 B 仍很差，先检查点击点是否在物体底部贴地处、相机高度/俯角是否记录正确，不要急着采满 200。

## 四、200 张怎么分配（建议）

| 地面 | 白天 | 夜间开灯 | 小计 |
|---|---|---|---|
| 瓷砖 | 40 | 30 | 70 |
| 木地板 | 35 | 25 | 60 |
| 地毯 | 40 | 30 | 70 |
| 合计 | 115 | 85 | **200** |

分 4 次采，每次 50 张（约 1 小时）；中途 `q` 退出，下次自动从已有图片数继续（断点续采）。

## 五、采完评测

```bash
# 先停掉在线服务，避免和 MPS 抢（或加 --cpu 慢一点）
ai312/bin/python scripts/eval_ep_ranging.py
```

输出 `results/ep_ranging_eval.json`，对比：

| 方法 | 说明 |
|---|---|
| A 固定针孔 | 现有系统假设：F=212px@640w、H=0.25m、俯角 0（预计误差最大） |
| B 地平面标定 | 拟合 `Z = a/(v - y_h)`，等价于标定相机高度/俯仰 |
| C 深度标定 | 拟合 `1/Z = a*disparity + b`（Depth Anything V2 相对深度） |

指标：AbsRel、RMSE、δ1（`max(est/gt, gt/est) < 1.25`）；按图片切分训练/测试，防同图泄漏。
**样本 <20 张时只作管线自检，不写结论。**

## 六、数据纪律（避免白采）

- 距离必须是卷尺/地砖量的，不能用“看着差不多”；
- 一张图里物体的地面接触点必须可见（被挡住就换角度）；
- 相机高度/俯仰一旦开始采集就不要改；改了要新开一个 `--out` 目录；
- 不拍人脸；只拍物品和地面；
- CSV 每行一个物体，`distance_m` 单位米；`u_px,v_px` 是地面接触点像素坐标。
