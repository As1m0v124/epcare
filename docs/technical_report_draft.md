# 技术报告（草稿 v0.3，2026-10-26）

> 阶段 3 要求 4–6 页技术报告；当前基于已完成的复现与系统骨架起草，接真机后补端到端数据。

## 摘要

面向独居老人家庭与养老机构的地面巡检整理机器人：以 RoboMaster EP 为平台，集成
单目深度估计（Depth Anything V2）、开放词汇检测（Grounding DINO）与大模型收纳偏好归纳（TidyBot），
配套网页系统（驾驶舱/巡检/找东西/收纳规则/告警/评测/看板/审计）与 CLI、MCP 接口。

## 1. 系统概述

- 硬件：EP 底盘 + 机械臂（前后/上下两个舵机）+ 机械爪 + 摄像头；手机热点组网（STA），Mac 控制；
- 控制服务（Python 3.8）：SDK 控制、TCP 40921 裸 H.264 视频解码、急停/限速/限幅/低电量拒动、审计；
- 后端（Python 3.12）：FastAPI + SQLite，三角色权限、任务、告警、规则、评测、看板；
- 前端：单页网页 10 个页面 + 侧边栏助手；CLI `epcare`；MCP Server。

## 2. 三个 AI 功能与结果

### F1 单目深度估计
- 方法：DA-V2 ViT-S 零样本；评测口径 MiDaS 尺度+偏移对齐；Eigen 裁剪；
- 结果：NYU-D 654 张 AbsRel **0.0624** / δ1 **0.9542**（论文 0.053 / 0.973）；
  DA-2K 2068 对准确率 **94.78%**（论文 95.3%）；
- 错例：远景动态范围压缩、镜面反射（详见 docs/f1_error_analysis.md）。

### F2 开放词汇定位
- 方法：Grounding DINO Swin-T（HF 实现）零样本；80 类 COCO 提示词；
- 结果：COCO 前 500 张 AP **43.4**、全量 4952 张 AP **40.8**（论文 48.4）；
  RefCOCO val **52.9%** / testA **55.5%** / testB **43.5%**（论文 50.41/57.24/43.21）。

### F3 大模型收纳偏好归纳
- 方法：TidyBot 官方提示词；本地 Qwen2.5-3B 替代已停用 OpenAI 接口（零成本）；
- 结果：TidyBot 20 场景 46.7% / 63.0%；96 场景 **46.9% / 64.3%**（论文 78.5% / 91.2%）；
  中文 40 场景 88.3% / 98.3%（自建场景偏简单，验证中文链路）；
- 结论：先归纳再推断优于只看示例（+17pp），与论文方向一致；绝对差距源于本地小模型。

## 3. 系统实现

- 驾驶舱：实时画面（回放/真机）、深度图叠加、开放词汇检测（框+分数+粗估距离）、急停、键盘遥控；
- 巡检任务：地标最近邻计划、replay 演练执行、历史任务；
- 找东西：中文指令→英文提示→检测→截图；「取回」演示动作序列（replay）；
- 收纳规则：示例→归纳（规则回退或本地 LLM）→保存与展示；
- 告警：拍照告警、处理闭环、审计记录；
- 评测页：读取 results/*.json 展示全部复现指标；看板聚合任务/告警/机器人状态；
- 安全：三角色权限（家属可急停、仅管理员改参数/解除急停）、限速/位移/机械臂限幅、低电量拒动。

## 4. 测试

- 冒烟测试：登录→连接回放→画面→深度→检测→任务→规则→评测→急停拦截，全部通过；
- 模拟用户测试（replay，3 角色 × 5 任务）：**通过率 100%（15/15）**，平均 1.7 步；
  详见 docs/sim_user_results.md（真机轮次待补）。
