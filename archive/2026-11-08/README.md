## 2. 舵机为什么不能线性控制

EP 机械臂只开放位置步进接口，没有可用速度接口：

- 底盘 `drive_speed` 给速度；机械臂 `robotic_arm.move(x,y)` 只有位置增量；
- `servo.drive_speed` 与高层位置控制互斥，实测失败/锁死，已禁用；
- SDK 动作通道一次只执行一个动作，高频小步报 `already performing`；单步 <8–10mm 被静默忽略；
- 只能 10mm 分步闭环：20/20 执行，平均误差 1.55mm、最大 2mm；是分段位置控制，不是匀速线性控制。
