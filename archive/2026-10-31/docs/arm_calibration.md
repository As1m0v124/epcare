# 机械臂工作空间标定（人工摆位 + 开机读数）

> 方法：关机后手动把机械臂摆到极限姿态 → 开机 → SDK 读取 (x, y)。
> 前提修复：SDK 位置解码为无符号整数会把负 y 显示成 4294967xxx，已改为有符号（`<ii`）。
> 原始记录：docs/arm_calibration.jsonl（每次开机的读数）。

## 四个角点（2026-10-31 实测）

| 姿态 | 位置 (x, y) mm | 时间 |
|---|---|---|
| 后收 + 最低 | **(80, 60)** | 16:47:51 |
| 后收 + 最高 | **(84, 167)** | 16:49:51 |
| 前伸 + 最低 | **(217, -53)** | 16:51:43 |
| 前伸 + 最高 | **(177, 137)** | 16:55:00 |

## 结论

1. **工作空间是曲面，不是矩形**：升降范围随前后位置变化很大
   - 后收（x≈80）时 y 可达 60 ~ 167；
   - 前伸（x≈217）时 y 约 -53 ~ 117；
   - 中间（x≈177）y 上限约 137。
2. **y 坐标可以为负**（前伸压低时到 -53），SDK 必须用有符号解码，否则会出现 42 亿这类异常值；
3. **软限位策略**：不做矩形硬截断（会把有效姿态误杀），改用「按住某方向无位移 → 判定到边界并提示」；
   前端：3 秒窗口 + 连续两次失败才提示「已到限位」。
4. 人工标定可重复：相同流程（关机摆位 → 开机读数），结果写入 docs/arm_calibration.jsonl。

## 复现命令

```bash

from robomaster import robot, config
from robomaster.conn import scan_robot_ip_list

PY
```
